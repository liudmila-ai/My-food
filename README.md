# Моя еда · v11

Offline-first версия PWA. Основная рабочая копия данных хранится на устройстве, Supabase используется для аккаунта и синхронизации.

## Что изменилось

- После хотя бы одного успешного входа приложение запускается без доступа к Supabase, VPN и даже без интернета.
- Профиль, семья, меню, избранное, личные граммовки, покупки и готовка читаются из локальной базы.
- Локальная база хранится в IndexedDB; localStorage оставлен как резервный совместимый слой.
- Любые изменения сразу сохраняются локально и помечаются как ожидающие синхронизации.
- При появлении доступа приложение автоматически пытается синхронизировать текущую локальную копию с Supabase.
- В шапке отображается статус: «Синхронизировано», «Офлайн», «Офлайн · N изм.» и т.п. По нажатию выполняется ручная синхронизация.
- В профиле добавлены «Синхронизировать сейчас», «Экспорт JSON» и «Импорт JSON».
- Supabase JS загружается в фоне. Его недоступность больше не мешает открыть локальное приложение.
- Service Worker кэширует интерфейс v11 и, после успешной загрузки, клиентскую библиотеку Supabase.

## Важное ограничение

Первый вход на новом устройстве, регистрация, подтверждение email, восстановление и смена пароля требуют доступ к Supabase. После первого успешного входа повседневная работа может идти локально.

## Обновление GitHub Pages

1. Загрузить все файлы из архива поверх текущих файлов репозитория.
2. Commit changes.
3. Дождаться GitHub Pages.
4. Один раз открыть сайт. В шапке должна отображаться v11.
5. Для первоначального входа после установки нужен доступ к Supabase. После этого локальная копия сохраняется на устройстве.

Кэш Service Worker: `moya-eda-v11`.
