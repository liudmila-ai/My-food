# Моя еда — PWA для iPhone

Готовая статическая PWA. Серверная часть не нужна.

## Что внутри
- 65 блюд из библиотеки питания
- поиск и фильтры
- избранное
- карточки блюд
- недельное меню
- расчёт КБЖУ выбранного дня
- список покупок
- локальное сохранение меню и настроек
- service worker для офлайн-работы после первого успешного открытия
- iPhone safe-area, Apple Touch Icon и standalone-режим

## Самый простой запуск на iPhone через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `my-food`.
2. Загрузите **все файлы из этой папки в корень репозитория**. Не загружайте ZIP как единственный файл.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем Save.
6. GitHub Pages выдаст HTTPS-адрес вида `https://username.github.io/my-food/`.
7. Откройте этот адрес на iPhone в Safari.
8. Нажмите `Поделиться → На экран «Домой» → Добавить`.

После установки приложение запускается отдельным окном с домашнего экрана. После первого успешного открытия основные файлы кэшируются для офлайн-работы.

## Важно
PWA требует HTTPS для service worker и полноценной установки. GitHub Pages уже предоставляет HTTPS.

Данные меню, избранного и чек-листа хранятся локально в браузере на конкретном устройстве через `localStorage`. Очистка данных Safari может их удалить.

## Локальная проверка на компьютере
Из папки проекта:

```bash
python -m http.server 8080
```

затем открыть `http://localhost:8080`.
