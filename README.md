# Моя еда · v7

PWA с отдельными аккаунтами Supabase.

## Что есть в v7
- регистрация по email и паролю;
- подтверждение email;
- вход / выход / восстановление пароля;
- отдельные данные для каждого пользователя через Supabase RLS;
- синхронизация меню недели, избранного, личных граммовок, покупок и готовки;
- локальный кэш для работы при временных проблемах сети;
- перенос данных v6 в первый аккаунт на устройстве;
- библиотека 65 блюд и экономная генерация недели.

## Перед публикацией
В Supabase открой `Authentication → URL Configuration`.

Укажи:
- **Site URL**: адрес GitHub Pages, например `https://USERNAME.github.io/my-food/`
- **Redirect URLs**: тот же адрес, можно добавить `https://USERNAME.github.io/my-food/**`

Email provider должен быть включён. Если включён Confirm Email, новый пользователь сначала подтверждает адрес из письма.

## Публикация
Загрузи все файлы этой папки поверх существующих файлов в репозитории GitHub Pages и сделай Commit.

После публикации в шапке должно быть `v7`.

## Безопасность
В `supabase-config.js` находится только Publishable key. Это клиентский публичный ключ. Никогда не добавляй в PWA `service_role`, Secret key или пароль базы данных.
