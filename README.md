# Моя еда PWA v6

## Что нового
- Экономный генератор недели: ограничивает набор основных белков и гарниров, чтобы одни базы использовались в разных блюдах.
- «Готовка» агрегирует курицу, индейку, говядину, крупы и овощи в общие партии вместо отдельной готовки каждого рецепта.
- Профили участников: отдельные цели КБЖУ, меню и избранное.
- Покупки и готовка можно считать по текущему профилю или сразу по всем выбранным участникам.
- Профиль открывается круглой кнопкой в правом верхнем углу.

## Важно про учётные записи
Сейчас профили локальные и хранятся на устройстве в localStorage. Это уже правильная структура данных для нескольких участников, но вход с разных телефонов требует backend-а (например Supabase/Firebase) и авторизации.
