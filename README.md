# Моя еда — PWA v3

Мобильный планировщик питания для iPhone и браузера.

## Что нового в v3

- «Составить всю неделю»: автоматически заполняет 7 дней по 4 приёма пищи.
- Автоплан стремится к ~1750 ккал и ~130 г белка в день.
- В карточке любого блюда есть кнопка «✎ граммовки».
- Граммовки задаются на 1 порцию и сохраняются локально на устройстве.
- Список покупок суммирует точные количества по всей выбранной неделе.
- Если у ингредиента количество ещё не задано, он выводится отдельным списком «Нужно внести граммовки».

## Как обновить GitHub Pages

Распакуйте архив и замените файлы в существующем репозитории содержимым этой папки. Сделайте Commit changes. GitHub Pages опубликует новую версию автоматически.

На iPhone установленная PWA может некоторое время использовать старый офлайн-кэш. После обновления откройте сайт в Safari один раз, затем полностью закройте и снова откройте приложение с домашнего экрана.
