# Моя еда · v9

PWA с Supabase-аккаунтом организатора и семейными участниками без отдельных аккаунтов.

## Новое в v9

- В аккаунте организатора появился раздел «Семья».
- Можно добавить любое число членов семьи: имя, калорийность и БЖУ.
- Для каждого участника доступны режимы «30/30/40» и собственные БЖУ.
- Участника можно временно выключить из расчётов, не удаляя его.
- Меню недели единое для всей семьи.
- При открытии блюда из плана показываются отдельные порции и граммовки для каждого включённого участника.
- «Покупки» суммируют ингредиенты всех включённых участников.
- «Готовка» суммирует общие белки, гарниры и овощные базы для всей семьи.
- Семья хранится в `user_settings` текущего Supabase-аккаунта. Дополнительный SQL не требуется.

## Как обновить GitHub Pages

1. Распакуйте архив.
2. Загрузите все файлы поверх текущих файлов репозитория.
3. Сделайте Commit changes.
4. Дождитесь публикации GitHub Pages.
5. Откройте сайт в Safari. В шапке должна отображаться версия v9.
6. Полностью закройте установленную PWA и откройте снова.

Service worker использует кэш `moya-eda-v9`.

## Логика семьи

Организатор имеет настоящий Supabase-аккаунт. Члены семьи являются записями внутри этого аккаунта и не могут входить в приложение самостоятельно.

Одно и то же меню используется для всех. Базовый рецепт масштабируется отдельно для каждого участника по его калорийности и доле приёма пищи: завтрак 25%, обед 30%, перекус 15%, ужин 30%.

Важно: без отдельной базы пищевой ценности каждого ингредиента приложение может масштабировать размер всей порции, но не перестраивать соотношение продуктов внутри одного рецепта для точного попадания в разные пользовательские БЖУ. БЖУ участника используются как цели и отображаются в профиле; точная нутриентная оптимизация ингредиентов — отдельный следующий слой.
