# Моя еда PWA v5

Исправленная версия для iPhone/GitHub Pages.

## Что исправлено
- кэш обновлён до `moya-eda-v5`;
- `app.js`, `data.js` и `styles.css` получают версионные URL;
- код приложения загружается network-first, поэтому новая версия не застревает в старом PWA-кэше;
- тап по блюду в «Сегодня» и «Неделе» открывает рецепт;
- отдельная кнопка «заменить» открывает выбор блюда;
- вкладка «Готовка» формирует план по текущей неделе;
- все 65 блюд имеют ингредиенты с количествами на 1 порцию.

## Обновление на GitHub Pages
Загрузите все файлы поверх старых и сделайте Commit changes. Затем один раз откройте сайт в Safari. В верхней строке приложения должно быть `v5`. После этого закройте установленную PWA из переключателя приложений и откройте снова.
