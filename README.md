# Моя еда — PWA v16

## Новое
- Пользовательские рецепты: создание, редактирование и удаление.
- Для рецепта задаются категория, КБЖУ, время, ингредиенты и граммовки, инструкция, хранение, замены и теги.
- Настраивается логика готовки: заранее, компоненты заранее, накануне, в день подачи или только сборка.
- Пользовательские рецепты участвуют в поиске, фильтрах, меню, автоподборе, закупках и недельной готовке.
- Пользовательские рецепты хранятся offline-first и синхронизируются в `user_settings` Supabase, отдельный SQL не нужен.
- Встроенные рецепты не удаляются.
