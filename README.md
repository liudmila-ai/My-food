# Моя еда PWA v4

Изменения v4:
- нажатие на блюдо в Сегодня и Неделе открывает рецепт; замена вынесена в отдельную кнопку;
- новая вкладка «Готовка» строит план приготовления по текущему меню;
- для всех 65 блюд добавлены ориентировочные граммовки на 1 порцию и рецепты;
- покупки суммируются по граммовкам всей недели.

## Обновление GitHub Pages
Загрузите все файлы из архива поверх файлов репозитория и сделайте Commit changes. После публикации один раз откройте сайт в Safari, затем закройте PWA и откройте снова.

Важно: веса круп, пасты и картофеля в базе указаны в готовом виде; мясо и рыба преимущественно в сыром. КБЖУ и граммовки ориентировочные и зависят от брендов и способа приготовления.
